# Interaction Skill

## Goal

Create a consistent interaction language across the configured product.

---

# States

Interactive components should support:

* Default
* Hover
* Focus
* Active
* Selected
* Disabled
* Loading
* Success
* Warning
* Error

---

# Motion

Use subtle transitions.

Recommended:

```text
150–250ms
```

Prefer:

* Opacity
* Transform
* Elevation
* Scale
* Color transitions

Avoid:

* Excessive bouncing
* Flashing
* Large rotations
* Continuous distracting animation

---

# Cards

Cards may respond to hover with:

* Slight elevation
* Subtle border change
* Small translate/scale

Do not make every card animated.

---

# Navigation

Active navigation should be immediately recognizable.

Use the configured primary color.

---

# 3D Interaction

3D elements should feel interactive but controlled.

Use:

* Hover highlight
* Selected room
* Contextual information
* Smooth transitions

Avoid aggressive camera movement.

---

# Feedback

Actions should provide immediate feedback.

Examples:

* Task completed
* Shopping item checked
* Expense added
* Event created
* Maintenance completed

Use appropriate configured success/error colors.

---

# Accessibility

Never communicate state using color alone.

Combine:

* Icon
* Text
* Shape
* Position
* Color
